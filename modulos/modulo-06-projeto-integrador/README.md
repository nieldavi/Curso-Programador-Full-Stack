# 🏆 Módulo 06: Projeto Integrador (Capstone)

O **Projeto Integrador** é o momento de consolidar todo o aprendizado adquirida ao longo da formação em um projeto prático completo, simulando os desafios reais do mercado de trabalho.

---

## 🎯 Requisitos Mínimos da Aplicação

Sua aplicação Full Stack deve contemplar:

1. **Front-end**:
   - Interface desenvolvida em **React.js** (ou HTML/CSS/JS avançado).
   - Design responsivo para mobile e desktop.
   - Consumo de dados via API REST.
   - Gerenciamento de rotas e telas de autenticação.

2. **Back-end**:
   - API RESTful construída em **Node.js + Express**.
   - Arquitetura limpa com rotas, controllers e services.
   - Autenticação de usuários via JWT.
   - Tratamento adequado de erros e validação de dados.

3. **Banco de Dados**:
   - Banco Relacional (**PostgreSQL** ou **MySQL**).
   - Mínimo de 3 tabelas relacionadas.
   - Persistência real dos dados através de ORM/Query Builder.

4. **Publicação (Deploy)**:
   - Front-end hospedado na Vercel ou Netlify.
   - Back-end hospedado na Render, Railway ou Fly.io.

---

## 📋 Etapas do Projeto

- **Semana 1**: Definição do Tema, Escopo e Modelagem do Banco (DER).
- **Semana 2**: Desenvolvimento da API Back-end e Banco de Dados.
- **Semana 3**: Desenvolvimento do Front-end em React.
- **Semana 4**: Integração Front + Back, Ajustes de UX/UI, Deploy e Apresentação Final.
