# 🌐 Módulo 01: Fundamentos Web & Git

Neste primeiro módulo, o aluno aprenderá as bases da construção de páginas para a Web, compreendendo como estruturar conteúdos semanticamente, estilizar interfaces responsivas e utilizar ferramentas de versionamento de código.

---

## 🎯 Objetivos de Aprendizagem

- Entender o funcionamento da Web (Cliente/Servidor, HTTP/HTTPS, DNS).
- Dominar a estrutura e tags semânticas do **HTML5**.
- Aplicar estilizações modernas com **CSS3** (Cores, Tipografia, Box Model, Flexbox e CSS Grid).
- Criar páginas totalmente responsivas utilizando **Media Queries**.
- Utilizar o **Git & GitHub** no dia a dia do desenvolvimento.

---

## 📅 Conteúdo das Aulas

1. **Aula 01**: Introdução à Web, Arquitetura Cliente-Servidor e Configuração do VS Code.
2. **Aula 02**: Estrutura Semântica em HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
3. **Aula 03**: Formulários e Elementos de Entrada (`<input>`, `<select>`, `<button>`).
4. **Aula 04**: Fundamentos de CSS3, Seletores, Cores, Fontes e Box Model.
5. **Aula 05**: Layouts Modernos com **Flexbox**.
6. **Aula 06**: Grid Layout e Design Responsivo (Mobile-First).
7. **Aula 07**: Versionamento de Código com **Git & GitHub**.
