# 🟢 Módulo 04: Back-end com Node.js & Express

O Módulo 04 inicia a jornada do aluno no desenvolvimento **Back-end**, ensinando como construir servidores seguros, performáticos e APIs RESTful.

---

## 🎯 Objetivos de Aprendizagem

- Entender o ecossistema do **Node.js** e o modelo de I/O não-bloqueante (Event Loop).
- Criar servidores HTTP eficientes utilizando o framework **Express.js**.
- Entender os Verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`) e Códigos de Status.
- Tratar dados em formato **JSON**, Query Params, Route Params e Request Body.
- Implementar middlewares de validação, tratamento de erros e CORS.
- Autenticação e Autorização usando **JWT (JSON Web Tokens)** e **Bcrypt** para criptografia de senhas.

---

## 📅 Conteúdo das Aulas

1. **Aula 01**: Introdução ao Node.js, NPM e Módulos Nativos.
2. **Aula 02**: Criando o primeiro servidor HTTP com Express.
3. **Aula 03**: Rotas e Parâmetros (`req.params`, `req.query`, `req.body`).
4. **Aula 04**: Padrão de Arquitetura (Controllers, Services, Routes).
5. **Aula 05**: Middlewares e Tratamento Global de Erros.
6. **Aula 06**: Autenticação com JWT e Criptografia de Senhas com Bcrypt.
7. **Aula 07**: Testes de API com Postman / Insomnia.

---
