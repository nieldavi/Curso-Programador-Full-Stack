# ⚛️ Módulo 03: Front-end com React.js

Neste módulo, avançamos no desenvolvimento Front-end utilizando a biblioteca mais popular do mercado: o **React.js**.

---

## 🎯 Objetivos de Aprendizagem

- Compreender a arquitetura baseada em **Componentes**.
- Trabalhar com **JSX** e renderização condicional/listas.
- Gerenciar o estado de componentes com `useState`.
- Lidar com efeitos colaterais e requisições com `useEffect`.
- Compartilhar informações através de **Props** e **Context API**.
- Navegação entre páginas com **React Router**.
- Estilização com **TailwindCSS** ou **CSS Modules**.

---

## 📅 Conteúdo das Aulas

1. **Aula 01**: Introdução ao React, Vite e estrutura de arquivos.
2. **Aula 02**: Componentes, JSX e Propriedades (`props`).
3. **Aula 03**: Gerenciamento de Estado (`useState`) e Eventos em React.
4. **Aula 04**: Ciclo de Vida e Efeitos (`useEffect`).
5. **Aula 05**: Formulários Controlados e Validação.
6. **Aula 06**: Roteamento Multi-páginas com React Router DOM.
7. **Aula 07**: Integração com APIs externas (Axios/Fetch) e Context API.
