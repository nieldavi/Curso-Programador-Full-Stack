# ⚡ Módulo 02: JavaScript & ES6+

O Módulo 02 é focado no desenvolvimento da lógica de programação e na linguagem de programação da web: o **JavaScript**.

---

## 🎯 Objetivos de Aprendizagem

- Compreender variáveis (`let`, `const`), tipos de dados e operadores.
- Utilizar estruturas condicionais (`if/else`, `switch`) e laços de repetição (`for`, `while`, `map`, `filter`, `reduce`).
- Criar funções tradicionais e **Arrow Functions**.
- Manipular a **DOM** (Document Object Model) para dar interatividade a páginas web.
- Tratar eventos de usuário (`click`, `submit`, `change`, `keydown`).
- Trabalhar com **JavaScript Assíncrono** (`Promises`, `Fetch API` e `async/await`).

---

## 📅 Conteúdo das Aulas

1. **Aula 01**: Variáveis, Tipos Primitivos e Operadores Aritméticos/Lógicos.
2. **Aula 02**: Estruturas de Controle e Decisão.
3. **Aula 03**: Funções, Parâmetros e Retornos.
4. **Aula 04**: Arrays e Métodos Modernos (`map`, `filter`, `find`, `reduce`).
5. **Aula 05**: Objetos e Desestruturação (Destructuring & Spread Operator).
6. **Aula 06**: Manipulação da DOM e Manipulação de Eventos.
7. **Aula 07**: Consumo de APIs REST com `fetch` e `async/await`.
