# 🗄️ Módulo 05: Banco de Dados Relacional & ORM

Neste módulo, o aluno aprende a persistir dados em bancos de dados relacionais e a conectar a aplicação Node.js ao banco através de ORMs modernos.

---

## 🎯 Objetivos de Aprendizagem

- Conceitos de Modelagem de Dados e Relacionamentos (1:1, 1:N, N:N).
- Linguagem **SQL** (DDL e DML: `CREATE TABLE`, `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `JOIN`).
- Instalação e uso de **PostgreSQL** ou **MySQL**.
- Integração do Node.js com Banco de Dados usando **Prisma ORM** ou **Knex.js**.
- Migrations, Seeds e integridade referencial.

---

## 📅 Conteúdo das Aulas

1. **Aula 01**: Introdução a Bancos de Dados e Modelagem Entidade-Relacionamento (DER).
2. **Aula 02**: Instalação e Comandos Básicos SQL (CRUD em SQL puro).
3. **Aula 03**: Relacionamentos e Junções (`INNER JOIN`, `LEFT JOIN`).
4. **Aula 04**: Introdução ao ORM (Prisma ORM / Knex).
5. **Aula 05**: Criando e Executando Migrations.
6. **Aula 06**: Conectando a API Node.js ao Banco de Dados.
7. **Aula 07**: Boas Práticas de Indexação, Performance e Segurança em DB.

---

## 📂 Arquivos de Exemplo

- `exemplos/scripts-sql/`: Scripts `.sql` de criação de tabelas e consultas.
- `exemplos/node-prisma-express/`: Projeto de API integrada ao PostgreSQL com Prisma.
