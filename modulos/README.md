# 📚 Módulos do Curso Programador Full Stack

Nesta pasta estão organizadas todas as seções de aprendizado do curso. Cada subpasta contém seu próprio guia de conteúdos, exemplos de código de aula e materiais de apoio.

- [`modulo-03-front-end-react/`](./modulo-03-front-end-react/): React.js, Componentes, Hooks, State, Tailwind.
- [`modulo-04-back-end-node/`](./modulo-04-back-end-node/): Node.js, Express, APIs RESTful, JWT.
- [`modulo-05-banco-de-dados/`](./modulo-05-banco-de-dados/): SQL, PostgreSQL/MySQL, ORM (Prisma/Knex).
- [`modulo-06-projeto-integrador/`](./modulo-06-projeto-integrador/): Aplicação Full Stack Capstone.
