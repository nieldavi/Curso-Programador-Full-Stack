# 📝 Atividades e Desafios Práticos por UC

Esta pasta é dedicada ao armazenamento das listas de exercícios, desafios práticos e materiais de apoio das **Unidades Curriculares (UCs)** do curso.

---

## 📂 Organização das Atividades por UC

- `uc1-atividades/`: Documentos de requisitos, protótipos Figma e tarefas Scrum.
- `uc2-atividades/`: Exercícios de HTML5, CSS3, JavaScript ES6+ e componentes React.
- `uc3-atividades/`: Desafios de versionamento Git e publicação (deploy).
- `uc4-atividades/`: Construção de rotas, controllers e autenticação em Node.js/Express.
- `uc5-atividades/`: Scripts SQL, modelagem DER e manipulação com Prisma ORM.
- `uc6-atividades/`: Consumo de APIs externas e documentação com Swagger.
- `uc7-atividades/`: Acompanhamento e entregáveis do Projeto Integrador.

---

## 📥 Instruções para Envio de Trabalhos pelos Alunos

1. Faça o **Fork** do repositório original para a sua conta do GitHub.
2. Crie a solução dentro da pasta da UC correspondente.
3. Faça o commit seguindo as [Boas Práticas de Git](../recursos/boas-praticas-git.md).
4. Abra um **Pull Request (PR)** apontando para o repositório do professor para avaliação.
