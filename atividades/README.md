# 📝 Atividades e Desafios Práticos

Esta pasta é dedicada ao armazenamento das listas de exercícios, desafios práticos e materiais de apoio das atividades do curso.

---

## 📂 Organização das Atividades

- `atividade-01-fundamentos-html-css/`: Exercício de criação de landing page responsiva.
- `atividade-02-logica-javascript/`: Desafios de lógica, funções e arrays.
- `atividade-03-manipulacao-dom/`: Construção de uma To-Do List interativa.
- `atividade-04-react-componentes/`: Projeto de consumo de API com React.
- `atividade-05-api-rest-node/`: Criação de uma API RESTful de cadastro com Express.
- `atividade-06-modelagem-sql/`: Scripts de criação e consulta em banco de dados.

---

## 📥 Instruções para Envio de Trabalhos pelos Alunos

1. Faça o **Fork** do repositório original para a sua conta do GitHub.
2. Crie a solução dentro da pasta da atividade correspondente.
3. Faça o commit seguindo as [Boas Práticas de Git](../recursos/boas-praticas-git.md).
4. Abra um **Pull Request (PR)** apontando para o repositório do professor para avaliação.
