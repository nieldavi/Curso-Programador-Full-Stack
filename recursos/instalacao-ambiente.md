# 💻 Guia de Configuração do Ambiente de Desenvolvimento

Para acompanhar as aulas práticas e desenvolver seus projetos, siga este passo a passo para instalar e configurar as ferramentas essenciais.

---

## 🛠️ 1. Editor de Código (VS Code)

O **Visual Studio Code** é o editor padrão utilizado no curso.

1. Baixe o instalador no site oficial: [code.visualstudio.com](https://code.visualstudio.com/)
2. Execute o instalador e marque as opções de **"Adicionar a opção 'Abrir com Code' ao menu de contexto"**.
3. **Extensões Recomendadas**:
   - **Live Server** (para visualizar páginas HTML/CSS em tempo real).
   - **Prettier - Code formatter** (para formatação automática de código).
   - **ES7+ React/Redux/React-Native snippets** (atalhos para código React).
   - **Auto Rename Tag** (renomeia tags HTML automaticamente).
   - **Material Icon Theme** (ícones de arquivos visuais e modernos).

---

## 🐙 2. Git (Controle de Versão)

O **Git** é fundamental para salvar o histórico de alterações e enviar códigos para o GitHub.

1. Baixe o Git em: [git-scm.com](https://git-scm.com/)
2. Instale mantendo as opções padrão recomendadas.
3. Após a instalação, abra o terminal (Prompt de Comando ou Git Bash) e configure seus dados:

```bash
git config --global user.name "Seu Nome Completo"
git config --global user.email "seu-email@exemplo.com"
```

---

## 🟢 3. Node.js (Ambiente de Execução JavaScript)

O **Node.js** é necessário para executar JavaScript no servidor e gerenciar pacotes com o `npm`.

1. Acesse: [nodejs.org](https://nodejs.org/)
2. Baixe a versão **LTS (Long Term Support)** recomendada para a maioria dos usuários.
3. Instale o pacote executável.
4. Para confirmar que a instalação deu certo, abra o terminal e digite:

```bash
node -v
npm -v
```

---

## 🚀 4. Ferramentas Auxiliares

- **Postman** (Testes de APIs REST): [postman.com/downloads](https://www.postman.com/downloads/)
- **DBeaver** ou **pgAdmin** (Gerenciador de Banco de Dados SQL): [dbeaver.io](https://dbeaver.io/)
- **Navegador**: Google Chrome ou Microsoft Edge com DevTools ativado (`F12`).
