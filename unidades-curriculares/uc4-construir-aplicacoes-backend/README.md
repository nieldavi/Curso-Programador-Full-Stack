# 🟢 UC4 - Construir Aplicações Back-End

A **UC4** aborda o desenvolvimento do lado do servidor (Back-End) utilizando **Node.js** e o framework **Express**, cobrindo arquitetura de software, tratamento de requisições, segurança e autenticação.

---

## 🎯 Competências e Indicadores

- Compreender a arquitetura do **Node.js** (Event Loop, Non-blocking I/O).
- Criar servidores web e roteamento com **Express.js**.
- Aplicar o padrão de arquitetura em camadas (Routes, Controllers, Services, Repositories).
- Implementar rotas e verbos HTTP (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`).
- Desenvolver middlewares para validação de dados, logs e tratamento de erros.
- Garantir a segurança da aplicação com **JWT (JSON Web Tokens)** e criptografia de senhas (**Bcrypt**).

---

## 📅 Conteúdo Programático

1. **Aula 01**: Introdução ao Node.js, NPM e estrutura de projetos servidor.
2. **Aula 02**: Criando servidores HTTP com Express.js e manipulando JSON.
3. **Aula 03**: Rotas, Query Params, Route Params e Request Body.
4. **Aula 04**: Arquitetura de Software: Controllers e Services.
5. **Aula 05**: Middlewares de Validação (Zod / Yup) e Tratamento de Exceções.
6. **Aula 06**: Autenticação de Usuários com JWT e Bcrypt.
7. **Aula 07**: Boas Práticas de Segurança em APIs (CORS, Rate Limiting, Helmet).
