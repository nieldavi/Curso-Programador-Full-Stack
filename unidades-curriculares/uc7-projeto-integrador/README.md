# 🏆 UC7 - Projeto Integrador Programador Full Stack

A **UC7** é a Unidade Curricular de culminância do curso. Nela, os alunos trabalham em equipe (ou individualmente) para desenvolver um projeto web completo e real, aplicando de forma articulada as competências das UCs 1 a 6.

---

## 🎯 Escopo do Projeto Integrador

A solução desenvolvida deve conter obrigatoriamente:

1. **Documentação & Planejamento (UC1)**: Requisitos, diagramas ER e protótipo interativo no Figma.
2. **Interface Front-end (UC2)**: Aplicação web responsiva desenvolvida em React.js.
3. **Publicação & Deploy (UC3)**: Aplicação hospedada e funcional na Nuvem (Vercel, Render, etc.).
4. **Servidor Back-end (UC4)**: API RESTful construída em Node.js com Express e autenticação JWT.
5. **Persistência de Dados (UC5)**: Banco de dados relacional (PostgreSQL/MySQL) integrado via ORM.
6. **Serviços Web & Documentação (UC6)**: Integração com serviços externos e API documentada com Swagger.

---

## 📅 Cronograma de Execução

- **Fase 1: Concepção**: Definição do problema, levantamento de requisitos e criação do protótipo no Figma (UC1).
- **Fase 2: Arquitetura & Banco**: Modelagem de dados, criação das tabelas e rotas da API em Node.js (UC4 e UC5).
- **Fase 3: Front-end & Integração**: Construção das telas em React e conexão com os serviços da API (UC2 e UC6).
- **Fase 4: Deploy & Apresentação**: Publicação em produção, testes finais e banca de apresentação do projeto (UC3 e UC7).

---

## 📋 Critérios de Avaliação

- Qualidade do código e aderência às boas práticas e convenções.
- Funcionalidade completa das operações CRUD e autenticação.
- Usabilidade, responsividade e fidelidade ao protótipo.
- Publicação funcional da aplicação (links ativos de Front e Back).
- Apresentação técnica da equipe.
