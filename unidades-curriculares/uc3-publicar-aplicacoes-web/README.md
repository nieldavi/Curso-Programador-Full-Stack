# 🚀 UC3 - Publicar Aplicações Web

A **UC3** ensina o aluno a preparar, versionar e realizar o deploy de aplicações web em provedores em nuvem, garantindo a disponibilidade e segurança dos projetos.

---

## 🎯 Competências e Indicadores

- Utilizar **Git** e **GitHub** para controle de versão profissional e colaboração.
- Configurar variáveis de ambiente (`.env`) e gerenciar segredos com segurança.
- Realizar o build de produção de aplicações Front-end e Back-end.
- Publicar aplicações Front-end em plataformas PaaS como **Vercel** e **Netlify**.
- Publicar aplicações Back-end e APIs em plataformas como **Render**, **Railway** ou **Fly.io**.
- Entender noções básicas de CI/CD (GitHub Actions) e configuração de domínios personalizados.

---

## 📅 Conteúdo Programático

1. **Aula 01**: Versionamento Avançado de Código com Git (Branches, Merge, Pull Requests).
2. **Aula 02**: Gestão de Variáveis de Ambiente e Segurança (`.env` e `.gitignore`).
3. **Aula 03**: Processo de Build e Otimização para Produção (Vite, Webpack, Bundlers).
4. **Aula 04**: Deploy de Front-end na **Vercel** e **Netlify**.
5. **Aula 05**: Deploy de Serviços Back-end e Node.js no **Render** / **Railway**.
6. **Aula 06**: Introdução a CI/CD com GitHub Actions.
7. **Aula 07**: Apontamento de DNS, Domínios Customizados e Certificados SSL (HTTPS).
