# 📐 UC1 - Elaborar Projetos de Aplicações para Web

A **UC1** aborda as fases iniciais do ciclo de vida de desenvolvimento de software, capacitando o aluno a planejar, especificar requisitos e criar protótipos de aplicações web.

---

## 🎯 Competências e Indicadores

- Levantamento e documentação de requisitos funcionais e não-funcionais.
- Criação de wireframes e protótipos de alta fidelidade no **Figma**.
- Definição da arquitetura da aplicação (Front-end, Back-end, Banco de Dados).
- Elaboração de diagramas de caso de uso e DER (Diagrama Entidade-Relacionamento).
- Gestão de tarefas e projetos com metodologias ágeis (**Scrum / Kanban / Trello / GitHub Projects**).

---

## 📅 Conteúdo Programático

1. **Aula 01**: Introdução à Engenharia de Software e ciclo de vida de aplicações web.
2. **Aula 02**: Engenharia de Requisitos (Requisitos Funcionais e Não-Funcionais).
3. **Aula 03**: UX/UI Design - Princípios de Usabilidade, Acessibilidade e Design System.
4. **Aula 04**: Prototipagem de Interfaces com **Figma** (Wireframes e Protótipos Interativos).
5. **Aula 05**: Arquitetura de Software e Diagramação (UML e Modelagem DER).
6. **Aula 06**: Metodologias Ágeis de Desenvolvimento (Scrum, Sprints, User Stories).
7. **Aula 07**: Apresentação da Proposta de Projeto e Documentação.
