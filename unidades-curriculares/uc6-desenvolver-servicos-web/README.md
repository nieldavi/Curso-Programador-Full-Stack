# 🔌 UC6 - Desenvolver Serviços Web

A **UC6** foca na criação, integração e documentação de **Web Services** e **APIs RESTful**, permitindo a comunicação entre sistemas heterogêneos e o consumo de serviços de terceiros.

---

## 🎯 Competências e Indicadores

- Projetar e desenvolver Web Services seguindo o padrão de arquitetura **REST**.
- Consumir APIs RESTful externas no Front-end (React/JS) e Back-end (Node.js) utilizando **Axios** e `fetch`.
- Documentar APIs de forma padronizada utilizando a especificação **OpenAPI / Swagger**.
- Integrar serviços de terceiros (autenticação social, gateways de pagamento, envio de e-mails, CEP/Geolocalização).
- Lidar com paginação, filtros, ordenação e versionamento de APIs (`/api/v1/...`).

---

## 📅 Conteúdo Programático

1. **Aula 01**: Princípios de Web Services, Arquitetura REST e Níveis de Maturidade de Richardson.
2. **Aula 02**: Consumo de Web Services Externos (ex: ViaCEP, MercadoPago, GitHub API).
3. **Aula 03**: Paginação, Filtros e Ordenação em Recursos de APIs.
4. **Aula 04**: Documentação Interativa de APIs com **Swagger (OpenAPI)** no Node.js.
5. **Aula 05**: Integração de Serviços de Envio de E-mails (Nodemailer / Resend) e Arquivos (Uploads/S3).
6. **Aula 06**: Webhooks e Arquitetura de Eventos Básica.
7. **Aula 07**: Testes de Integração de Serviços Web com Postman / Jest.
