# 🗄️ UC5 - Implementar Banco de Dados para Web

A **UC5** capacita o aluno a modelar, criar e manipular bancos de dados relacionais e não-relacionais, além de conectar a base de dados a aplicações web através de ORMs.

---

## 🎯 Competências e Indicadores

- Modelar dados utilizando Diagrama Entidade-Relacionamento (DER) e Normalização.
- Executar comandos SQL (DDL e DML) em SGBDs relacionais como **PostgreSQL** ou **MySQL**.
- Realizar consultas avançadas utilizando `JOINs`, agregações (`GROUP BY`, `COUNT`) e subconsultas.
- Integrar bancos de dados a aplicações Node.js utilizando **Prisma ORM** ou **Knex.js**.
- Gerenciar alterações de esquema utilizando **Migrations** e dados de teste com **Seeds**.
- Noções de bancos de dados NoSQL (ex: **MongoDB**).

---

## 📅 Conteúdo Programático

1. **Aula 01**: Conceitos de Bancos de Dados, SGBDs e Modelagem Relacional (DER).
2. **Aula 02**: Instalação do PostgreSQL / MySQL e interface visual (DBeaver / pgAdmin).
3. **Aula 03**: Linguagem SQL: Criação de Tabelas (DDL) e Manipulação de Dados (DML).
4. **Aula 04**: Consultas Avançadas: `INNER JOIN`, `LEFT JOIN`, Filtros e Agregações.
5. **Aula 05**: Introdução ao Prisma ORM: Configuração, Schema e Migrations.
6. **Aula 06**: Conectando a API Node.js/Express ao Banco de Dados via ORM.
7. **Aula 07**: Transações, Indexação e noções de Bancos NoSQL.

---
