# 📚 Unidades Curriculares (UCs) - Programador Full Stack

Nesta pasta estão organizadas todas as **Unidades Curriculares (UCs)** do plano de curso oficial do Senac. Cada diretório contém o detalhamento das competências, conteúdos programáticos, aulas e exemplos práticos.

---

## 🗂️ Matriz Curricular do Curso

| UC | Nome da Unidade Curricular | Descrição Resumida | Diretório |
| :---: | :--- | :--- | :--- |
| **UC1** | **Elaborar projetos de aplicações para web** | Requisitos, arquitetura, prototipagem (Figma), metodologias ágeis e planejamento. | [`uc1-elaborar-projetos-web/`](./uc1-elaborar-projetos-web/) |
| **UC2** | **Construir aplicações front-end** | HTML5, CSS3, JavaScript ES6+, manipulação da DOM e React.js. | [`uc2-construir-aplicacoes-frontend/`](./uc2-construir-aplicacoes-frontend/) |
| **UC3** | **Publicar aplicações web** | Versionamento Git/GitHub, hospedagem em nuvem (Vercel, Render), domínios e CI/CD. | [`uc3-publicar-aplicacoes-web/`](./uc3-publicar-aplicacoes-web/) |
| **UC4** | **Construir aplicações Back-End** | Node.js, Express, arquitetura de APIs RESTful, middlewares e autenticação (JWT). | [`uc4-construir-aplicacoes-backend/`](./uc4-construir-aplicacoes-backend/) |
| **UC5** | **Implementar banco de dados para web** | SQL, PostgreSQL/MySQL, modelagem de dados, Prisma ORM e migrations. | [`uc5-implementar-banco-de-dados/`](./uc5-implementar-banco-de-dados/) |
| **UC6** | **Desenvolver serviços web** | Web Services RESTful, consumo de APIs externas, Swagger/OpenAPI e integração de serviços. | [`uc6-desenvolver-servicos-web/`](./uc6-desenvolver-servicos-web/) |
| **UC7** | **Projeto Integrador Programador Full Stack** | Projeto prático final de consolidação de todas as competências do curso. | [`uc7-projeto-integrador/`](./uc7-projeto-integrador/) |
