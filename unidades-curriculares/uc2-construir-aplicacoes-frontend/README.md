# 🎨 UC2 - Construir Aplicações Front-End

A **UC2** capacita o aluno a desenvolver interfaces web interativas, acessíveis e responsivas, utilizando as principais tecnologias do mercado para Front-end.

---

## 🎯 Competências e Indicadores

- Estruturar páginas web com **HTML5** semântico.
- Estilizar elementos com **CSS3** avançado (Flexbox, CSS Grid, Transições, Animações e Responsividade).
- Aplicar lógica de programação no navegador com **JavaScript ES6+**.
- Manipular elementos da **DOM** e tratar eventos de usuário.
- Construir Single Page Applications (SPAs) modernas com **React.js** (Componentes, Props, Estados, Hooks).

---

## 📅 Conteúdo Programático

1. **Aula 01**: Estrutura Semântica em HTML5 e Acessibilidade (ARIA).
2. **Aula 02**: Estilização com CSS3: Box Model, Flexbox e CSS Grid.
3. **Aula 03**: Layouts Responsivos e Mobile-First com Media Queries e TailwindCSS.
4. **Aula 04**: Lógica de Programação com JavaScript ES6+ (Arrow Functions, Arrays, Destructuring).
5. **Aula 05**: Manipulação de DOM e Gerenciamento de Eventos.
6. **Aula 06**: Fundamentos de React.js: JSX, Componentização e Props.
7. **Aula 07**: Gerenciamento de Estado (`useState`) e Efeitos (`useEffect`) em React.

---

## 📂 Recursos e Materiais

- `exemplos/01-pagina-responsiva/`: Projeto básico com HTML5 + CSS Flexbox/Grid.
- `exemplos/02-componentes-react/`: Exemplos de componentes reutilizáveis em React.
